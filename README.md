## 🏥 Acerca de KATIANA

**KATIANA** es una plataforma e-commerce farmacéutica diseñada a partir del análisis de las **5 droguerías más exitosas de Colombia**:

1. **Farmatodo:** Experiencia digital express, entrega en 45 minutos ("Katiana Ya"), barra interactiva de envío gratis y dermocosmética líder.
2. **Cruz Verde:** Módulo de validación de fórmulas médicas (RX vs OTC) y programa de lealtad con descuentos por cédula (Club Katiana).
3. **Droguerías La Rebaja:** Cercanía 24/7, canal directo con químicos regentes por WhatsApp y foco en medicamentos genéricos accesibles de alta calidad.
4. **Farmacias Pasteur:** Ficha técnica y registro sanitario INVIMA verificado para cada producto, especialidad en cuidado cutáneo.
5. **Cafam / Farmalisto:** Protocolo estricto de cadena de frío y checkout omnicanal preparado para pago contra entrega, datáfono, PSE y billeteras móviles (Nequi / Daviplata).

## 🚀 Inicio Rápido en Local

### En Windows (Doble Clic):
Haz doble clic en `start-demo.cmd`. Abrirá automáticamente `http://127.0.0.1:8095/` en tu navegador.

### Con Python:
```bash
python -m http.server 8095
```

## 📦 Despliegue en Producción

### 1. Repositorio en GitHub
El proyecto está sincronizado en:
👉 **[https://github.com/Salman-Contructora-Inmobiliaria/katiana-web](https://github.com/Salman-Contructora-Inmobiliaria/katiana-web)**

### 2. GitHub Pages
Ve a `Settings` -> `Pages` -> Selecciona la rama `main` (o GitHub Actions) y el sitio quedará publicado gratis.

### 3. Vercel (Con Soporte Gemini AI)
Importa el repositorio en Vercel y añade `GEMINI_API_KEY` en tus variables de entorno para potenciar a la **Dra. Katiana (Asistente Farmacéutica IA)**.
